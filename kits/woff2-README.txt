== 內容 ==
ChangMingSerifTC-Regular.woff2   400 字重（{{SIZE_400}}）
ChangMingSerifTC-Bold.woff2      700 字重（{{SIZE_700}}）
OFL.txt                          字型授權

每個檔案包含完整字形，瀏覽器會整檔下載。適合 App 內嵌、離線頁面，或想自行
子集化、處理載入方式的專案。一般網站建議改用「網頁字型包」，只會下載用到的字。

== @font-face 範例 ==
@font-face {
  font-family: "ChangMing Serif TC";
  font-weight: 400;
  font-display: swap;
  src: url("ChangMingSerifTC-Regular.woff2") format("woff2");
}
@font-face {
  font-family: "ChangMing Serif TC";
  font-weight: 700;
  font-display: swap;
  src: url("ChangMingSerifTC-Bold.woff2") format("woff2");
}
body { font-family: "ChangMing Serif TC", Georgia, serif; }
